# NTU Sentinels website

A minimal Jekyll template for the NTU Sentinels cybersecurity club. The home page has a block-character heading and placeholder paragraph; the other page bodies are intentionally empty while the site layout is being designed.

The navbar links are configured in `_data/navigation.yml`. Add page content in `_pages/` when it is ready.

[JetBrains Mono](https://github.com/JetBrains/JetBrainsMono) and the linked [particles.js v2.0.0](https://vincentgarreau.com/particles.js/) are stored locally in `assets/`. Their license notices are in `licenses/`. The particle background is disabled when reduced motion is requested.

To preview locally, run `jekyll serve` from this directory and open `http://127.0.0.1:4000/`.
